# BridgeFood

A non-commercial prototype for Indian restaurant discovery and simulated food ordering, starting with fictional Leicester restaurants.

## Stack
- React + TypeScript + Vite
- FastAPI + Python
- PostgreSQL using Docker

## Milestone 1
The initial project archive contains the frontend, backend, Docker Compose configuration, synthetic restaurant seed data, and local setup instructions.

**Prototype only:** fictional restaurants, synthetic data and simulated orders. No real payments, live delivery, commercial restaurant onboarding, or real customer data.

## Run locally
1. Extract the project archive into this repository.
2. Start PostgreSQL: `docker compose up -d db`
3. Follow the Windows setup steps in the project README.
